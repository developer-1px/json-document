# Hands

Hands는 idiom의 최소 완성본입니다. 제품이 아니고 컴포넌트도
아닙니다. 그 장르의 전형적 손만 보여 줍니다.

구현이 없는 손은 TBD로 남기고, 화면 위젯으로 대체하지 않습니다.
TBD 페이지의 코드는 사용법 명세입니다. 패키지에 아직 없습니다.
